# Chapter 2 — Math for Data Science

Tổng quan: các kiến thức toán cần thiết cho Data Science (đại số tuyến tính, xác suất & thống kê, tối ưu hoá cơ bản).

Mục tiêu bài học:
- Hiểu ma trận, phép biến đổi tuyến tính
- Xác suất cơ bản và biến ngẫu nhiên
- Thống kê mô tả và suy luận

Yêu cầu trước: Python cơ bản, làm quen với Jupyter Notebook.

Tài liệu và files:
- `notebooks/` — notebook ví dụ (nếu có)
- `exercises/` — bài tập cho sinh viên
- `slides/` — slide buổi học

Hướng dẫn nhanh để bắt đầu:
```
# (tại thư mục này hoặc nhánh gốc)
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt  # nếu có
```
